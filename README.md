# “Turon Odob-Ilm” Xususiy Maktabi (Furqat) — 1:1 Old & Orqa 3D Loyihasi (v2.3)

Farg‘ona viloyati, Furqat tumani (**A-376** magistrali) da joylashgan **“Turon odob-ilm” xususiy maktabi** majmuasining old va orqa qismlari 1:1 aniqlikda qurilgan interaktiv 3D modeli hamda 2D chizmalari.

## v2.3 yangilanishlari
- **3 ta Bir xil Yotoqxona qanoti:** Markaziy Damas yo‘lagi ikki chetidagi 2 ta parallel Yotoqxona to‘riga xuddi shunaqa dizayndagi **O‘g‘il bolalar yotoqxonasi** (`50.5 × 7.0 m`) ulanib ketgan holda qurildi (qora bino o‘rniga).
- **Tekis ochiq tuproq maydon:** Basketbol maydoni va ortiqcha jihozlar olib tashlanib, maydon oddiy tekis tuproq holatiga keltirildi; Turnik chetroqda, atrofida keng o‘tish yo‘li bilan joylashtirildi.
